# ToestemmingsWijzer Jeugdhulp

Een hulpmiddel van Jolanda Winters voor jeugdprofessionals: wie moet toestemming geven voor jeugdhulp, op basis van de Jeugdwet, de WGBO (Boek 7 BW) en Boek 1 BW.

De app draait volledig in de browser. Er is geen server en geen database. Er worden geen gegevens opgeslagen of verstuurd. Lettertypes zitten in de app zelf.

## Lokaal draaien

1. `npm install`
2. `npm run dev`

## Online zetten

Vercel herkent dit als Vite-project. Build-commando `npm run build`, uitvoermap `dist`.
